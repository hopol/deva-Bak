向下滚动，看它怎么做
01 · 挂载工作区

说要看哪个项目，点一下就挂上

未挂载时它会弹出卡片请你选文件夹；挂上之后，这个对话就围绕这个项目干活。

02 · 动手干活

自己找文件、改代码、跑测试

每一步都在对话里看得见；步骤多的活儿列成待办清单，边做边勾，做完收成一张卡片。

03 · 子代理并行

大任务拆开，几个子代理同时跑

每个子代理有独立上下文，翻过的文件不占主对话，只把结论交回来；不急的还能放到后台。

04 · 提问卡

需要你拍板时，给你选项

带推荐项，也能自己输入；答完收起成一行，不占地方。

05 · 计划批准

大活先列计划，你批准才动手

不满意就点「继续完善」让它接着改；点「批准并执行」后才开始改代码。

06 · 定时任务

一句话建定时任务

核对时间和指令后点创建；到点自动运行、全程不打扰，跑完弹系统通知。

07 · 新建角色

一句话新建角色

它把性格、风格、常用模型拟成一张角色名片，确认后就多了一个专门的助手。

08 · 回退

改坏了，退回去

输入 /rewind 或连按两次 Esc，回到任意一轮之前；代码和对话可分开恢复，回退了还能撤销。

09 · 手机上接着聊

人不在电脑前，手机上接着聊

接入飞书或 Telegram，扫码就配好；手机上发的消息，就是在这个对话里继续聊。

还有这些

不挂文件夹时，它是面向整台电脑的通用助手；挂上一个文件夹，它就围绕这个项目工作。

多角色，各有所长

内置全能助手 Deva 和安全研究专家小码酱；自己建的角色也有独立的性格、头像和常用模型。

记住你的习惯

说一句「记住…」它就记下，以后每次对话都参考；也能只记在某个项目里，不进仓库、别人看不到。

技能与 MCP

用 /技能名 调出写好的做事方法，也能上传技能包；接入 MCP 服务扩展数据库、浏览器等外部工具。

像聊天软件一样用

Git 快捷操作

挂载的是 Git 仓库时，旁边显示当前分支，拉取、推送、切换分支、提交一点就好，提交信息可以让 AI 来写。

BEFORE YOU START

用之前要知道的

Deva 追求「说了就做」，所以有几件事请先了解。

动手前不会逐个询问

读写文件、跑命令都直接执行，不弹授权框。重要的项目建议用 Git 管着，或者先备份。

数据都在本机

设置、对话、记忆、任务都放在 ~/.deva，API 密钥加密保存。用 IM 机器人时，手机上的对话会经过对应平台。

第一次打开被系统拦住？
  • Windows：弹出「Windows 已保护你的电脑」时，点「更多信息」→「仍要运行」。
  • macOS：提示无法验证 Deva.app 是否包含恶意软件时，选择「完成」，前往「系统设置 → 隐私与安全性」点击「仍要打开」，然后重新打开 Deva 并在弹窗中确认。若提示应用「已损坏」或未出现「仍要打开」选项，在终端执行： 
    xattr -cr /Applications/Deva.app
